# Admin / Consultant / Customer Workflow

## Administrator mode

- Dashboard
- Users
- Analysis
- Forum
- Premium
- Consult
- Staff
- Admin profile

## Consultant mode

1. Open Live Consultancy.
2. Review waiting requests.
3. Accept a request.
4. Read the conversation.
5. Reply to the customer.
6. Resolve the consultation.

## Customer preview mode

1. Open the administrator mode selector.
2. Select My Customer Dashboard.
3. Review the signed-in administrator's own customer data.
4. Use the existing customer experience, including profile, wardrobe, analysis and AI styling.
5. Return to Administrator through the Admin navigation item.

## Acceptance criteria

- Switching modes resets the selected navigation index.
- Consultant conversations are read-only before acceptance.
- Only the assigned consultant can reply or resolve a consultation.
- Customer preview must remain limited to the signed-in administrator's own customer data.
- Returning to Administrator resets the destination to Dashboard.
